> **وضعیت:** یک پروژه **استاتیک و شخصی‌سازی‌پذیر** برای نمایش یک نامه دیجیتال است؛ سامانه ارسال پیامک، ایمیل یا پیام‌رسانی مستقل نیست. GitHub Pages قبلاً با موفقیت منتشر شده، اما تست زنده مرورگر و ارسال واقعی پیامک در این بررسی مجدداً اجرا نشده است.

## معرفی

Roses Mail یک تجربه چندمرحله‌ای موبایل‌فرست است: بازدیدکننده پاکت نامه شیشه‌ای را باز می‌کند، متن روی یک برگه تیره نمایش داده می‌شود، سپس می‌تواند وارد تقویم شود و در صورت تمایل، تاریخ و متن خودش را به یک **پیش‌نویس SMS** اضافه کند.

محتوای متنی به‌طور مستقل در `content.js` تعریف شده است؛ در نتیجه می‌توان متن نامه و پیام‌ها را بدون تغییر منطق ناوبری یا طراحی ویرایش کرد.

## قابلیت‌های موجود

| بخش | رفتار واقعی در سورس |
| --- | --- |
| **پاکت نامه متحرک** | بازشدن تعاملی پاکت، تار شدن پس‌زمینه و نمایش نامه |
| **ویدئو و موسیقی** | `Rosita.mp4` به‌عنوان ویدئوی پس‌زمینه، تصویر جایگزین و `Lovly.mp3` برای موسیقی |
| **مراحل تعاملی** | پاکت، نامه، تقویم و صفحه پایانی به همراه ناوبری |
| **تقویم** | انتخاب و مشاهده تاریخ با تقویم‌های شمسی و میلادی؛ امکان ادامه بدون انتخاب تاریخ |
| **متن دلخواه** | نمایش کادر تکمیل پیام پس از انتخاب تاریخ |
| **SMS** | ساخت لینک `sms:` حاوی تاریخ و پیام فقط پس از تکمیل شرایط فرم |
| **نمایش موبایل** | طراحی RTL، کنترل‌های قابل تعامل و پشتیبانی از `prefers-reduced-motion` |

**درباره پیامک:** کلیک روی لینک SMS فقط تلاش می‌کند **نرم‌افزار پیامک دستگاه** را با متن آماده باز کند؛ ارسال نهایی به تصمیم و تأیید شخص در همان نرم‌افزار وابسته است. خود وب‌سایت پیامکی ارسال نمی‌کند، تحویل را پیگیری نمی‌کند و نمی‌تواند ارسال موفق را تضمین کند. در دسکتاپ یا مرورگرهای فاقد پشتیبانی `sms:` ممکن است این قابلیت کار نکند.

## اجرای محلی

از ریشه مخزن:

```bash
git clone https://github.com/cianium/Rosemail.git
cd Rosemail
python3 -m http.server 8080
```

سپس آدرس **http://localhost:8080** را در مرورگر باز کنید. در Termux نیز می‌توان پس از نصب Git و Python، پروژه را در یک پوشه عادی Termux کلون و با همان دستور اجرا کرد.

**توجه:** نسخه فعلی مخزن فایل `Roses-Mail-personal-SMS.zip` ندارد؛ دستور استخراج ZIP در مستندات قدیمی برای این مخزن معتبر نیست.

## شخصی‌سازی

فایل `content.js` برای ویرایش عنوان‌ها، پاراگراف‌های نامه، متن نهایی و عبارت‌های مربوط به پیامک استفاده می‌شود.

- `letterParagraphs` — پاراگراف‌های نامه
- `finalParagraphs` — پیام‌های صفحه پایانی
- `smsOpeningLine` و `smsText` — متن آغازین و پیشوند تاریخ برای SMS
- `smsRecipient` — گیرنده پیش‌فرض پیامک؛ برای انتخاب گیرنده در نرم‌افزار پیامک، آن را **خالی** بگذارید

### حریم خصوصی — قبل از به‌اشتراک‌گذاری سایت بخوانید

تمام مقادیر `content.js` به‌صورت **عمومی در مرورگر بازدیدکنندگان قابل مشاهده‌اند**. اگر در این فایل شماره تلفن، نام، تاریخ یا محتوای شخصی واقعی وجود داشته باشد، انتشار عمومی وب‌سایت عملاً آن اطلاعات را در معرض مشاهده قرار می‌دهد. **قبل از ارسال لینک به دیگران، این فایل را بررسی و مقادیر خصوصی را حذف یا با رضایت صاحب اطلاعات منتشر کنید.**

در سورس فعلی برای این فرایند بک‌اند یا ثبت تاریخ و پیام در `localStorage` وجود ندارد؛ متن فرم و تاریخ انتخابی در حافظه صفحه نگه داشته می‌شوند و با تازه‌سازی صفحه از بین می‌روند. لینک `sms:` متن آماده‌شده را به برنامه پیامک می‌سپارد و هزینه احتمالی پیامک بر عهده ارسال‌کننده است.

ویدئو، فایل صوتی و تصویر نیز باید از نظر **اجازه انتشار و حق استفاده** بررسی شوند. خود عمومی‌بودن مخزن GitHub مجوز بازنشر رسانه‌ها نیست.
